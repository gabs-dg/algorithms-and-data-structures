## 📚 Sobre o repositório

Este repositório foi criado com o objetivo de **praticar programação, algoritmos e estruturas de dados** por meio de problemas disponíveis no **LeetCode**.

Os exercícios estão organizados de acordo com seus diferentes níveis de dificuldade, permitindo acompanhar a evolução desde problemas mais simples até desafios mais complexos.

O foco principal é desenvolver:

- 🧩 Raciocínio lógico
- 🧠 Resolução de problemas
- ⚡ Eficiência e complexidade de algoritmos
- 🗂️ Estruturas de dados
- 💻 Boas práticas de programação
- 🔍 Capacidade de analisar e otimizar soluções

---

## 🎯 Objetivo

O principal objetivo deste projeto é transformar a resolução de problemas em uma prática constante.

Cada exercício representa uma oportunidade para estudar um determinado conceito, testar diferentes abordagens e entender como construir soluções mais eficientes.

> **Resolver problemas não é apenas encontrar uma resposta, mas entender o caminho utilizado para chegar até ela.**

---

## 📊 Níveis de dificuldade

Os exercícios estão divididos em três categorias principais:

| Dificuldade | Descrição |
|---|---|
| 🟢 **Easy** | Problemas introdutórios e conceitos fundamentais |
| 🟡 **Medium** | Problemas que exigem maior raciocínio e combinação de conceitos |
| 🔴 **Hard** | Problemas mais complexos, com maior exigência algorítmica |

### 🟢 Easy

Exercícios de nível introdutório, utilizados principalmente para desenvolver fundamentos de programação e lógica.

- Arrays
- Strings
- Loops
- Condicionais
- Hash Tables
- Two Pointers
- Estruturas básicas

### 🟡 Medium

Problemas que exigem uma análise mais cuidadosa e, muitas vezes, a utilização de estruturas de dados ou técnicas específicas.

- Binary Search
- Stack
- Queue
- Linked List
- Recursion
- Sliding Window
- Trees
- Graphs

### 🔴 Hard

Problemas que apresentam maior complexidade e exigem conhecimento mais avançado de algoritmos e estruturas de dados.

- Dynamic Programming
- Graph Algorithms
- Backtracking
- Advanced Trees
- Greedy Algorithms
- Advanced Data Structures

## 📝 Sobre as soluções

Cada exercício busca não apenas apresentar uma solução, mas também servir como material de estudo.

Sempre que possível, serão considerados:

1. **Entendimento do problema**
2. **Estratégia utilizada**
3. **Implementação**
4. **Complexidade de tempo**
5. **Complexidade de espaço**
6. **Possíveis otimizações**

Exemplo:

```text
Problema
   ↓
Entendimento
   ↓
Estratégia
   ↓
Implementação
   ↓
Análise de complexidade
   ↓
Otimização
```

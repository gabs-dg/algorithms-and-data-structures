# ➕ Mais Um (Plus One)

[![LeetCode](https://img.shields.io/badge/LeetCode-Problem-orange)](https://leetcode.com/problems/plus-one/)

**Dificuldade:** 🟢 Fácil
**Tópicos:** Array, Matemática

---

## 📌 Descrição

É dado um **número inteiro grande** representado como um vetor de inteiros `digits`, onde cada elemento `digits[i]` representa um dígito do número.

Os dígitos estão ordenados do **mais significativo para o menos significativo**, da esquerda para a direita.

O número inteiro não possui zeros à esquerda.

A tarefa é **incrementar o número inteiro em `1`** e retornar o array de dígitos resultante.

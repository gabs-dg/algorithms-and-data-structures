# 📏 Comprimento da Última Palavra

[![LeetCode](https://img.shields.io/badge/LeetCode-Problem-orange)](https://leetcode.com/problems/length-of-last-word/)

**Dificuldade:** 🟢 Fácil
**Tópicos:** String

---

## 📌 Descrição

Dada uma string `s` composta por palavras e espaços, retorne o **comprimento da última palavra** na string.

Uma **palavra** é uma substring composta apenas por caracteres que não sejam espaços.

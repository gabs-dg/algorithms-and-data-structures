# 🔎 Posição de Inserção de Pesquisa

**Dificuldade:** 🟢 Easy  
**Categoria:** Binary Search  
**Linguagem:** TypeScript

---

## 📌 Descrição

Dado um array de inteiros **distintos e ordenados em ordem crescente** e um valor `target`, retorne o índice caso o valor seja encontrado.

Caso o `target` não esteja presente no array, retorne o índice onde ele deveria ser inserido para manter a ordem crescente.

A solução deve possuir **complexidade de tempo `O(log n)`**.

🔗 **Problema no LeetCode:**  
[Search Insert Position](https://leetcode.com/problems/search-insert-position/)
